This is my **practical learning space**.

## 🔬 Lab Philosophy

I try to follow a simple approach:

### 1. Learn 📚

Understand the concepts and read the documentation.

### 2. Build 🔨

Create a small working environment.

### 3. Experiment 🧪

Change things and see what happens.

### 4. Break 💥

Sometimes things will fail.

That's part of the process.

### 5. Troubleshoot 🔍

Read logs, inspect configurations, test connectivity, and find the problem.

### 6. Improve 🚀

Fix the setup and try to make it better.

### 7. Document 📝

Document what I learned so I can come back to it later.
